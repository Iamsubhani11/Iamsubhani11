"01" / ENGINEERING PROFILE

I'm a Robotics Engineering student interested in building intelligent machines that connect mechanical systems, electronics, control engineering, and software.

My work spans ROS 2 robotics, digital twins, PLC-based industrial automation, embedded systems, and robot simulation. I enjoy taking a system from its model and control logic to simulation and, wherever supported by the project, real hardware.

FOCUS       Robotics · Industrial Automation · Embedded Systems
BUILD       Simulate → Control → Integrate → Test
INTERESTS   Robot Intelligence · Computer Vision · Autonomous Systems
